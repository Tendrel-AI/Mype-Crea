# KAN-33 — Logo output safety check (RF-02c)

Status: **approved 2026-11-03** (owner batch rule).

## Context

RF-02c asks that every generated logo keep the result and the version/provenance of a minimal
safety classifier, and that a rejected or indeterminate output is never presented as a final,
approvable logo. Logos are generated by fal.ai FLUX.2 [dev] (`fal-ai/flux-2`, `fal-ai/flux-2/edit`)
in `src/services/image/fal-provider.ts`. Both endpoints have a built-in safety checker
(`enable_safety_checker`, default true) and return `has_nsfw_concepts: boolean[]`.

## Decisions

1. **Classifier: the provider's own safety checker.** The request sends
   `enable_safety_checker: true` explicitly. `has_nsfw_concepts[0]` maps to the verdict:
   `false` → `passed`; `true` → `rejected` with category `sexual_content`; missing or not a
   boolean → `indeterminate`. A fal `content_policy` error stays the existing failed task
   (category `content_policy`, no image).
2. **Provenance on the deliverable.** The handler records
   `metadata.safety = { verdict, category | null, classifier: 'fal-safety-checker', model: <fal
   model id>, policyVersion: 'logo-safety.v1', checkedAt }`, stored in
   `deliverables.artifact_metadata`. No migration.
3. **Indeterminate is treated like rejected** (fail closed), and so is a malformed record.
   Deliverables without a record (text deliverables, logos generated before KAN-33, which fal
   checked by default) are unaffected.
4. **Review path (pilot).** A non-passed logo is stored (provenance, audit) but its URL never
   reaches a client: `clientDeliverableUrl` returns null for it. The card shows «Este logo no
   pasó la revisión automática de seguridad. Genera otra opción.» instead of the image, offers
   Generar and Iterar, and never offers «Aprobar» for it. The server refuses its approval with
   `not_allowed`. The rule is generic (`approvable` on the candidate view, from
   `src/core/deliverable-safety.ts:isPresentable`), not a logo branch in the core.
5. **Out of scope for the pilot:** human review by a platform operator, other classifiers or
   categories, re-classifying stored images.
